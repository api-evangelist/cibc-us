# CIBC Bank USA (cibc-us)

CIBC Bank USA is an Illinois state-chartered, FDIC-insured commercial bank (FDIC Cert #33306) headquartered at 120 South LaSalle Street in Chicago, Illinois. Formerly The PrivateBank and Trust Company, it was acquired in 2017 and rebranded, and operates today as a wholly owned US subsidiary of Canadian Imperial Bank of Commerce (CIBC) via the holding company CIBC Bancorp USA Inc. The bank serves commercial banking, capital markets, wealth management, trust, and private banking clients with North American operations.

## Open Finance / API Posture

CIBC Bank USA publishes **no first-party public developer portal or open API program**. Probes of the usual developer hostnames (`developer.cibc.com`, `developer.us.cibc.com`, `api.us.cibc.com`) do not resolve to a US developer portal, and the public `us.cibc.com` site contains no developer or API documentation.

- **First-party developer API:** None documented.
- **FDX (Financial Data Exchange):** Not a documented direct participant.
- **CFPB Section 1033:** No explicit published data-access posture for the US bank.
- **Aggregator access:** Consumer-permissioned data is reached only through third-party aggregators. CIBC is listed by [Plaid](https://plaid.com/institutions/cibc/) (Assets, Auth, Balance), and the CIBC group holds a data-access agreement with MX.

This is an honest identity-only (built-stub) profile: no public API surface exists to harvest, and data access is aggregator-mediated.
